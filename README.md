# Doggie Estética Animal - Landing Page

Responsive landing page for Doggie grooming business in São Bernardo do Campo.

## Features
- Mobile-first responsive design
- Service cards with WhatsApp booking integration
- Floating contact button
- Local business schema for SEO
- Fast load times (no external dependencies)

## Tech Stack
- HTML5
- CSS3 (CSS Variables, Flexbox, Grid)
- Vanilla JavaScript

## Structure
- `index.html` - Main page
- `css/styles.css` - All styles, design system
- `js/main.js` - Service data, DOM rendering
- `assets/` - Logo, favicon

## How to Run Locally
1. Clone repo
2. Open `index.html` in browser
3. Or run local server: `python -m http.server 8000` (Python 3)

## Deployment
- Static files ready for hosting (GitHub Pages, Netlify, Vercel)
- No backend required
- No build process needed
